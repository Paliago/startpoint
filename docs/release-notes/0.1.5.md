## What's new

- **Rune is now the sole native frontend**, using Rune Kit and Rune FX. Windows uses DX12; Apple Silicon macOS uses Metal.
- **Integrated Windows top bar:** minimize, maximize/restore and close sit inside the right-hand action island, without a separate title strip. Navigation, search and settings sit on the left, with the screen tabs alongside them.
- **Distinct build identities:** published Rune packages use a blue icon. Local builds, including optimized builds, use an amber **Startpoint Rune Dev** icon and a separate Windows taskbar group.
- **Classic Recents and Infinite Wall**, continuous Library layouts, activity history, editable metadata/artwork and Steam shortcut launch routes are available in the Rune application.
- **Independent per-game tasks** and a standalone Markdown journal with dated, author-attributed entries.
- A developer component-effects workbench is available through `--developer-tools`.

## Before upgrading

- Back up your library database before the first launch. This version uses **schema 4**; older executables refuse newer databases, so do not rely on downgrading without a backup.
- If an existing `rune-preview` library is present, Startpoint continues using that database and its matching cache. Canonical and Rune preview libraries are not merged or overwritten. Settings shows the active paths.
- Artwork, metadata, preferences, journal entries and tasks remain in the chosen existing library. Local development branding does not change storage paths.
- Native window-placement restoration, broader accessibility/IME acceptance and some platform integrations remain follow-up work. See the desktop architecture documentation in the tagged source for details.
